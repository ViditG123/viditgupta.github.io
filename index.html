04 — Engineering focus

What I'm
exploring.

A closer look at the engineering problems that shape my projects: evaluation, reliability, and testable financial workflows.

I

Evaluating AI Agents Beyond a Single Score

AgentBench focuses on comparing tool use, task completion, accuracy, and latency across repeatable test suites.

A useful evaluation workflow needs more than one headline number. Tracking experiments and inspecting failure patterns makes it easier to understand where an agent succeeds, where it struggles, and how changes affect performance.

II

Designing Background Jobs for Failure

CloudPulse explores asynchronous workers, retry policies, job-status tracking, and recovery paths.

Background work should be observable and resilient. Explicit job states, controlled retries, and clear failure handling help make distributed workflows easier to debug and operate.

III

Testing Critical Financial Workflows

LedgerGuard combines data validation, reconciliation, API integration tests, and browser automation.

Financial workflows depend on consistent data and predictable behavior. Pairing validation pipelines with automated regression tests helps catch discrepancies early and verify important user journeys.
